This app is a developer tool for generating realistic sample health data in Apple HealthKit. It is intended for developers, QA engineers, and testers who need to populate HealthKit with test data for app development and testing purposes.

To test the app:
1. Launch the app and grant HealthKit permissions when prompted.
2. On the Manual tab, select a health profile (e.g., "Athletic") and tap "Generate".
3. Open Apple Health app to verify the generated data.
4. Use the "Clean Up" button to remove generated test data.

The app does not collect, transmit, or store any user data externally. All health data is generated locally and written directly to the on-device HealthKit store.

The AI-powered generation feature requires iOS 26.0+ with Apple Foundation Models. On earlier iOS versions, only manual generation is available.
